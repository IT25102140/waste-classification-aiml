# Final Modeling Dataset

The final modeling dataset for the Waste Classification AIML project is stored in Google Drive and is intentionally excluded from GitHub.

## Dataset Access

Open the complete final dataset:

https://drive.google.com/drive/folders/1ktSl2yZ-ALsrz5cN_skvRyKg6TLNqvTk?usp=drive_link

## Dataset Statistics

| Split | Images |
|---|---:|
| Train | 1,826 |
| Validation | 389 |
| Test | 388 |
| **Total** | **2,603** |

## Classes

- Hazardous
- Non-Recyclable
- Organic
- Recyclable

## Dataset Structure

- train/
- validation/
- test/

## Frozen Split

The official frozen split is documented in `results/outputs/frozen_train_val_test_split.csv`.

## Reproducibility

The preprocessing pipeline is documented through the six member notebooks and `group_pipeline.ipynb`.

Supporting manifests, specifications, and audit reports are stored under `results/outputs/` and `audit_reports/`.

## GitHub / Google Drive Policy

The image files are intentionally not committed to GitHub. GitHub contains the project code, notebooks, manifests, specifications, documentation, and audit evidence. The actual final image dataset is available through the Google Drive link above.
